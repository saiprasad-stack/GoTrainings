# Cloud Basics

## 1. Cloud Computing

### Definition
Cloud computing is the delivery of computing services such as servers, storage, networking, databases, and software over the internet.

### Key Idea
- On-demand resources
- Pay only for what you use
- No physical infrastructure management

---

## 2. Data Center

### Definition
A physical facility that houses servers, storage systems, and networking equipment.

### Key Idea
- AWS owns and manages data centers
- You never interact with them directly

---

## 3. Server

### Definition
A computer that provides services or resources to other computers (clients).

### Key Idea
- Can host websites, APIs, databases
- Always running and accessible

---

## 4. Virtual Machine (VM)

### Definition
A virtualized computer running on a physical server using a hypervisor.

### Key Idea
- Isolation between applications
- Efficient resource usage

---

## 5. Operating System (OS)

### Definition
Software that manages hardware and provides an environment to run applications.

### Examples
- Linux
- Windows

---

## 6. CPU (Compute Power)

### Definition
The component responsible for executing instructions.
---

## 7. Memory (RAM)

### Definition
Temporary storage used by programs during execution.

---

## 8. Storage

### Definition
System used to store data persistently.

### Types

#### Block Storage
- Works like a hard disk
- Used for OS and databases

#### Object Storage
- Stores files like images, videos
- Highly scalable

#### File Storage
- Shared file system across multiple machines

---

## 9. Networking

### Definition
The system that connects computers and allows communication.

---

## 10. IP Address

### Definition
A unique identifier assigned to a device in a network.

---

## 11. DNS (Domain Name System)

### Definition
System that translates domain names into IP addresses.

---

## 12. Bandwidth

### Definition
The amount of data that can be transmitted per second.

---

## 13. Latency

### Definition
Time taken for data to travel from source to destination.

---

## 14. Load Balancer

### Definition
Distributes incoming traffic across multiple servers.

---

## 15. Scalability

### Definition
Ability to handle increasing or decreasing load.

### Types

#### Vertical Scaling
Increase resources of a single server

#### Horizontal Scaling
Add more servers

---

## 16. High Availability

### Definition
Ensuring systems are operational with minimal downtime.

---

## 17. Fault Tolerance

### Definition
System continues to function even when some components fail.

---

## 18. Virtual Private Cloud (VPC)

### Definition
A logically isolated network in the cloud.

---

## 19. Subnet

### Definition
A smaller network within a VPC.

### Types
- Public subnet (internet access)
- Private subnet (no direct internet access)

---

## 20. Firewall / Security Group

### Definition
Controls incoming and outgoing traffic.

---

## 21. Identity and Access Management (IAM)

### Definition
Manages users, roles, and permissions.
---

## 22. Region

### Definition
A geographical location where cloud data centers exist.

### Example
Mumbai, US-East

---

## 23. Availability Zone (AZ)

### Definition
Isolated data centers within a region.

---

## 24. Content Delivery Network (CDN)

### Definition
Distributes content closer to users for faster delivery.

### Simple Explanation
Serves data from the nearest location.

---

## 25. API (Application Programming Interface)

### Definition
A way for software systems to communicate.

### Simple Explanation
Messenger between systems.

---

## 26. Pay-as-you-go Pricing

### Definition
Pricing model where you pay only for used resources.

### Simple Explanation
No upfront cost, pay for usage.

---

🐳 Docker:Cheat Sheet

1. Verify Docker Installation

COMMAND
docker --version
Docker version 24.0.7, build afdd53b
COMMAND
docker run hello-world
Hello from Docker!
This message shows that your installation appears to be working correctly.

2. Pull an Image from Docker Hub

COMMAND
docker pull nginx:latest
latest: Pulling from library/nginx
a2abf6c4d29d: Pull complete
Digest: sha256:...
Status: Downloaded newer image for nginx:latest

3. Run a Container in the Foreground

COMMAND
docker run nginx
/docker-entrypoint.sh: /docker-entrypoint.d/ is not empty...
📌 Press Ctrl+C to stop the container.

4. Run a Container in Detached Mode (Background)

COMMAND
docker run -d --name my-nginx nginx
abc123def456789...
📌 The container keeps running even after closing the terminal.

5. List Containers

Running containers

docker ps
CONTAINER ID   IMAGE     COMMAND                  CREATED         STATUS         PORTS     NAMES
abc123def456   nginx     "/docker-entrypoint.…"   2 minutes ago   Up 2 minutes   80/tcp    my-nginx

All containers (including stopped)

docker ps -a
CONTAINER ID   IMAGE         COMMAND                  STATUS                     NAMES
abc123def456   nginx         "/docker-entrypoint.…"   Up 2 minutes               my-nginx
def456abc789   hello-world   "/hello"                 Exited (0) 5 minutes ago   wonderful_gates

6. View Container Logs

docker logs my-nginx
/docker-entrypoint.sh: /docker-entrypoint.d/ is not empty...
2024/04/01 12:34:56 [notice] 1#1: start worker process 30
Add -f to follow logs in real time: docker logs -f my-nginx

7. Execute Commands Inside a Container

docker exec -it my-nginx bash
root@abc123:/# ls
bin  boot  dev  etc  home  ...
Type exit to leave the shell without stopping the container.

8. Stop, Start, Restart Containers

docker stop my-nginx
docker start my-nginx
docker restart my-nginx

9. Map Host Ports to Container Ports

First, stop and remove the existing container:
docker stop my-nginx
docker rm my-nginx
Now run a new container with port mapping:
docker run -d --name my-nginx -p 8080:80 nginx
🌐 Open http://localhost:8080 in your browser – you'll see the Nginx welcome page.

10. Use Docker Volumes (Persistent Data)

Create a volume

docker volume create my-data
my-data

Mount it to a container

docker run -d --name data-container -v my-data:/data alpine sleep infinity

Write a file inside the container

docker exec data-container sh -c "echo Hello > /data/test.txt"

Verify persistence after container removal

docker stop data-container && docker rm data-container
docker run --rm -v my-data:/data alpine cat /data/test.txt
Hello

11. Bind Mount a Host Directory

mkdir -p ./html
echo "<h1>Hello from bind mount</h1>" > ./html/index.html
docker run -d --name dev-nginx -v $(pwd)/html:/usr/share/nginx/html -p 8081:80 nginx
📁 Visit http://localhost:8081 to see your custom HTML.

12. Set Environment Variables

docker run -d --name mysql-db -e MYSQL_ROOT_PASSWORD=secret mysql:8
The variable MYSQL_ROOT_PASSWORD is available inside the container.

13. Inspect a Container (Detailed JSON)

docker inspect my-nginx
[{
  "Id": "abc123def456...",
  "State": { "Status": "running", "Pid": 1234 },
  ...
}]

14. Pause and Unpause a Container

docker pause my-nginx
docker unpause my-nginx

15. Remove Containers

docker rm my-nginx          # works only if stopped
docker rm -f my-nginx       # force stop and remove

16. Remove Images

List images

docker images
REPOSITORY     TAG       IMAGE ID       CREATED         SIZE
myapp          1.0       abc123def456   2 hours ago     350MB
nginx          latest    ghi789jkl012   3 days ago      142MB

Remove an image

docker rmi nginx:latest
Untagged: nginx:latest

17. Clean Up Unused Resources

Basic prune (containers, networks, dangling images, build cache)

docker system prune
WARNING! This will remove:
  - all stopped containers
  - all networks not used by at least one container
  - all dangling images
  - all dangling build cache

Are you sure you want to continue? [y/N] y
Deleted Containers: ...
Total reclaimed space: 123.4MB

Prune everything including all unused images and volumes

docker system prune -a --volumes

18. Multi‑Container Apps with Docker Compose

Create a docker-compose.yml file:
cat > docker-compose.yml <

Start services in the background

docker-compose up -d
Creating network "default" with the default driver
Creating compose_web_1 ... done
Creating compose_db_1  ... done

List services

docker-compose ps
Name                Command               State          Ports
compose_db_1   docker-entrypoint.sh postgres    Up      5432/tcp
compose_web_1  /docker-entrypoint.sh ngin ...   Up      0.0.0.0:8080->80/tcp

View logs of a specific service

docker-compose logs web

Stop and remove everything (including networks)

docker-compose down -v

19. Additional Useful Commands

Live resource usage stats

docker stats
CONTAINER ID   NAME         CPU %     MEM USAGE / LIMIT     NET I/O
abc123def456   my-nginx     0.02%     12.34MiB / 7.789GiB   1.2kB / 456B

Copy files between host and container

docker cp ./index.html my-nginx:/usr/share/nginx/html/
docker cp my-nginx:/var/log/nginx/access.log ./access.log

20. Custom Network

Create a custom network

docker network create mynet
abc123def456789...

List networks

docker network ls

Connect a container to a network

docker network connect mynet my_container

Volume commands (manage named volumes)

docker volume ls
docker volume inspect myvol
docker volume rm myvol
